# JDBC y CRUD con MySQL

Proyecto Backend Java desarrollado como parte de la formación de EBAC, enfocado en persistencia de datos mediante JDBC.

## Funcionalidades

- Conexión con MySQL.
- Operaciones CRUD.
- Manejo de entidades Java.
- Acceso y persistencia de datos.
- Separación de responsabilidades mediante clases de contexto y operaciones.

## Tecnologías

- Java
- JDBC
- MySQL
- Maven

## Uso

Configura una instancia de MySQL y los parámetros de conexión correspondientes antes de ejecutar las operaciones de persistencia.

El proyecto utiliza Maven para la gestión de dependencias.
